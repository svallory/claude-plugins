# OKF

Create, validate, and enrich Open Knowledge Format (OKF) bundles — the open spec for representing organizational knowledge as markdown files with YAML frontmatter. Covers v0.2 provenance, trust, lifecycle, and Attested Computations.

```
/plugin install okf@tutor
```

See the [okf source](https://github.com/svallory/claude-plugins/tree/main/src/plugins/okf) for full documentation.
