# Demo Video

Produce narrated, subtitled MP4 demos of web-app features: Playwright records the browser with an animated cursor, ffmpeg assembles takes paced by TTS narration, with optional title cards, subtitles, and an outro slate.

```
/plugin install demo-video@tutor
```

See the [demo-video source](https://github.com/svallory/claude-plugins/tree/main/src/plugins/demo-video) for full documentation.
