# Tutor

Tutor your AI Agents to make them better.

Tutor is a Claude Code plugin marketplace: a collection of plugins and skills that teach coding agents new workflows, from adversarial text humanization to dev-team orchestration to demo-video production.

## Where to go

- **[Docs](/docs)** — what each plugin does and how to install it.
- **[Contribute](/contribute)** — how the build works, and how to add a plugin or skill.

## Quick install

```
/plugin marketplace add svallory/claude-plugins
```

Then install any plugin listed under [Docs](/docs).
