# Team Lead

Act as a dev team leader: decompose tasks, spawn developer agents at the cheapest adequate model, review their work, and track progress across a batch (sprint, board, epic, list of tickets).

```
/plugin install team-lead@tutor
```

See the [team-lead source](https://github.com/svallory/tutor/tree/main/src/plugins/team-lead) for full documentation.
