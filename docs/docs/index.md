# Docs

Plugins available in the Tutor marketplace.

| Plugin | Description |
|--------|-------------|
| [Ghostwriter](/docs/ghostwriter) | Adversarial AI text detection and humanization system. |
| [Team Lead](/docs/team-lead) | Dev team leader: decomposes tasks, spawns developer agents, reviews their work. |
| [Demo Video](/docs/demo-video) | Narrated, subtitled MP4 demos of web-app features. |
| [OKF](/docs/okf) | Create, validate, and enrich Open Knowledge Format bundles. |
| [Decompose](/docs/decompose) | Structured problem decomposition for hard problems. |

## Install

```
/plugin marketplace add svallory/tutor
```

Then install any plugin by name — see each plugin's page for its exact install line.

This is a skeleton. Full user-facing guides live on each plugin's own README until they're ported here.
